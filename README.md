# 🎬 Movie Explorer

A modern movie discovery web application built with **React**, **Vite**, **Tailwind CSS**, and **The Movie Database (TMDB) API**.

Users can browse trending movies, search by title, explore detailed movie information, watch trailers, discover cast members, filter by genres, and manage their favorite movies through a clean and interactive interface.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/Movie-Explorer.git
```

Go to the project folder

```bash
cd Movie-Explorer
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
VITE_TMDB_API_KEY=YOUR_API_KEY
```

Run the development server

```bash
npm run dev
```
